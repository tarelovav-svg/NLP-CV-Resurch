# NLP-CV-Resurch
Изучение моделей обработки текстовой информации и изображений объектов, эмбеддинг данных NLP+CV.
Первый этап - обработка текстовых обращений граждан. Классификация по принадлежности к ответственной службе рассмотрения обращений.
Используется модифицированный набор данных test_dataset_test.csv (https://www.kaggle.com/datasets/dimka11/classification-of-citizens-appeals/data).
Классификация по пяти классам: 'Благоустройство и комфортная городская среда', 'Улично-дорожная сеть и транспорт', 'Коммунальные ресурсы', 'Многоквартирные дома и управляющие компании', 'Социальная сфера'.
